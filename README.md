# 点字リアルタイム翻訳(プロトタイプ)

スマホ・PC のカメラや画像から日本語点字(6点式)を検出し、墨字(普通の文字)に翻訳するウェブアプリ。
Google レンズの翻訳のように、カメラをかざすとリアルタイムで認識することを目指す。

## 起動方法

```bash
python3 -m http.server 8642
```

を実行して <http://localhost:8642> を開く。
(カメラ機能はセキュアコンテキストが必要なため、`file://` では動かない。localhost は OK)

## 構成

| ファイル | 役割 |
|---|---|
| `braille.js` | 日本語点字の変換テーブルと双方向変換(かな・濁音・半濁音・拗音・数字・アルファベット・主な記号) |
| `vision.js` | 画像処理: 適応的二値化 → 点検出 → ピッチ推定 → セル格子当てはめ |
| `app.js` | UI・カメラ(getUserMedia)・デモ画像生成 |
| `index.html` | 画面 |

## 対応済み

- 五十音・濁音・半濁音・拗音(きゃ/ぎゃ/ぴゃ 等)・促音・長音
- 数符+数字、外字符+アルファベット(大文字符対応)
- 句読点・疑問符・感嘆符
- 複数行、マス空け(スペース)
- デモモード: テキスト→点字画像を生成して認識(エンドツーエンドの自己検証用)
- 処理速度は 1 フレーム数ms〜数十ms でリアルタイム動作可能

## 今後の課題

1. **実物の(浮き出た)点字の認識** — 影・ハイライトしか写らないため照明に弱い。
   斜め光なら「明るい点」モード+感度調整で読める可能性があるが、
   本格対応には機械学習(点検出モデル)が必要。これが最大の技術課題。
2. **傾き補正** — 現在はほぼ水平に撮影する前提。回転推定を追加したい。
3. **数学点字(数式)・理科(化学式)・点字楽譜** — それぞれ別体系の規則。
   `braille.js` のモード(仮名/数字/外字)を拡張する形で追加できる設計にしてある。
4. **iOS アプリ化** — 同じロジックを WKWebView でラップするか、Swift + Vision framework で
   ネイティブ実装。カメラを常時使うならネイティブが有利。
