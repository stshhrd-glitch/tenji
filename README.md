# 点字リアルタイム翻訳(プロトタイプ)

スマホ・PC のカメラや画像から日本語点字(6点式)を検出し、墨字(普通の文字)に翻訳するウェブアプリ。
Google レンズの翻訳のように、カメラをかざすとリアルタイムで認識することを目指す。

## 起動方法

```bash
python3 -m http.server 8642
```

を実行して <http://localhost:8642> を開く。
(カメラ機能はセキュアコンテキストが必要なため、`file://` では動かない。localhost は OK)

## 構成

| ファイル | 役割 |
|---|---|
| `braille.js` | 日本語点字の変換テーブルと双方向変換(かな・濁音・半濁音・拗音・数字・アルファベット・主な記号) |
| `vision.js` | 画像処理: 適応的二値化 → 点検出 → ピッチ推定 → セル格子当てはめ |
| `app.js` | UI・カメラ(getUserMedia)・デモ画像生成 |
| `index.html` | 画面 |

## 対応済み

### 点字表記(日本点字表記法・日本点字図書館「点字一覧表」準拠)
- 五十音・濁音・半濁音・拗音(きゃ/ぎゃ/ぴゃ 等)・促音・長音
- 特殊音(ファ・ティ・ディ・トゥ・ウィ・ヴァ・シェ・チェ・ツァ 等)
- 数符+数字(小数点・位取り点)、外字符+アルファベット(大文字符・二重大文字符)、外国語引用符
- 句読点・疑問符・感嘆符・中点・カギ括弧
- 同形符号の文脈判別(外字符/読点、疑問符/特殊音符、句点/濁特殊音符、濁音符/中点)
- 複数行、マス空け

### 画像認識
- 検出モード: 自動判別 / 印刷(暗い点・明るい点) / 実物の浮き出し点字
- **浮き出し点字**: 斜め光で「点の片側が明るく反対側が暗く」写る性質を利用した
  ハイライト+影のペア検出(点字OCR研究の定石)。裏点(両面印刷)は逆向きペアとして除外
- 傾き補正(±20°程度)・孤立ノイズ除去・行単位の品質ゲート
- 格子確定後に各マスの6点位置を直接サンプリングして点の有無を相対判定
- 処理速度は 1 フレーム数ms〜数十ms でリアルタイム動作可能

## 今後の課題

1. **実物点字の実写での精度向上** — 合成画像では検証済みだが、実写は照明・ボケ・
   遠近ゆがみの条件が厳しい。実写サンプルでの改善サイクルが必要。
   最終的には点検出の機械学習モデル(既存研究では CNN 物体検出)が本命。
2. **点字仮名遣い→墨字の変換** — 点字では助詞「は→わ」「へ→え」、オ列長音「ー」で
   書かれるため、漢字仮名交じりへの変換には日本語処理が必要(現状は発音通りに出力)。
3. **数学点字(数式)・理科(化学式)・点字楽譜** — それぞれ別体系の規則。
   `braille.js` のモード(仮名/数字/外字)を拡張する形で追加できる設計にしてある。
4. **iOS アプリ化** — 同じロジックを WKWebView でラップするか、Swift + Vision framework で
   ネイティブ実装。カメラを常時使うならネイティブが有利。
